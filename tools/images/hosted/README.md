# Hosted pictures

Pictures the app loads from this folder (through raw.githubusercontent.com) because their source
has no still image to link to, such as a frame taken from a video. Each one's credit and licence
is in src/data/images.json.

- alopias-pelagicus-hunting.jpg: a frame at 10.5 s from "Thresher-Sharks-Use-Tail-Slaps-as-a-Hunting-Strategy-pone.0067380.s002.ogv"
  on Wikimedia Commons (Oliver S, Turner J, Gann K, Silvosa M, D'Urban Jackson T, 2013, PLOS ONE; CC BY 2.5),
  contrast slightly raised. Used for the common thresher: it shows a pelagic thresher hunting sardines.
